投诉批办单管理系统（统信 UOS / 麒麟 Kylin V10）

一、选择正确的包
  在终端执行 uname -m：
    输出 x86_64   → complaints-linux-x86_64.tar.gz（Intel/AMD、兆芯、海光）
    输出 aarch64  → complaints-linux-aarch64.tar.gz（飞腾、鲲鹏、麒麟芯、瑞芯微等 arm64 国产 CPU）
  两个包不能混用：包内可执行文件和 _internal 下的 .so 是对应架构的原生机器码。

二、运行
  解压后双击「投诉批办单管理系统」或「启动GUI.sh」，也可终端执行：
      ./启动GUI.sh
  命令行批处理模式：
      ./启动命令行.sh

三、系统要求
  - 统信 UOS 20+ / 麒麟 Kylin V10 SP1+（构建基线 Ubuntu 22.04，glibc 2.35+）
  - 图形环境 X11 / Wayland + Tk 8.6（python3-tk）
  - 已安装 libreoffice-writer（Word 转 PDF / .doc 读取 / 打印前转换），或 WPS
  - 已安装 cups-client 并配置好打印机（lp 命令）
  - 已安装中文字体 fonts-noto-cjk（界面与文档显示）
  - 已安装 xdg-utils（xdg-open，用于打开文档与目录）

四、旧系统 / 其他架构（龙芯 LoongArch、申威等）
  源码为纯 Python，与 CPU 架构无关，可直接源码运行：
      sudo apt install python3 python3-tk python3-pip python3-venv \
                       fonts-noto-cjk libreoffice-writer cups-client xdg-utils
      python3 -m pip install -r requirements-linux.txt
      ./启动GUI.sh
  如需原生可执行文件，在目标机器上执行：
      python3 -m pip install -r requirements-linux.txt
      python3 -m PyInstaller complaints-linux.spec --noconfirm
  产物在 dist/投诉批办单管理系统/。

五、数据位置
  配置与数据库保存在程序目录下的 AppData/ 中，
  待打印 / 已打印 / 已处理 三个目录与程序同级，与 Windows 版一致。
