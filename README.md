# 投诉批办单自动生成应用

## 功能说明

自动批量处理目录中的PDF和Word文件，提取表格数据并生成规范的投诉批办单Word文档。

## 快速开始

### 方法一：使用批处理文件（推荐）
双击运行 `运行.bat` 文件即可

### 方法二：命令行运行
```bash
# 1. 首次使用需安装依赖
pip install -r requirements.txt

# 2. 运行程序
python main.py
```

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 方法一：GUI图形界面（推荐）

1. 双击运行 `启动GUI.bat`
2. 或命令行运行：`python gui_app.py`
3. 在图形界面中操作

**GUI主要功能**：
- ✨ 批量处理源文件
- ✏️ 可视化编辑生成的文档
- 🚀 快捷填充常用内容
- 🖨️ 批量打印功能
- 📊 统计报表生成
- ⚙️ 编号管理

详见：[GUI使用说明.md](GUI使用说明.md)

### 方法二：命令行方式

1. 将待处理的PDF文件和Word文件放在程序所在目录
2. 确保目录中有模板文件：`投诉批办单示例#1.docx`
3. 运行程序：

```bash
python main.py
```

4. 生成的Word文档将保存在`待打印`目录中

## 功能特性

- ✅ 自动扫描并批量处理PDF和Word文件
- ✅ 持久化编号管理（程序重启后继续递增）
- ✅ 保持模板原有格式（字体、段落样式）
- ✅ 自动生成当前日期
- ✅ 自动递增文件编号和收文编号

## 数据映射

### PDF文件处理
- PDF第2页第1行第2列 → 来文字号
- PDF第2页第3行第3列 → 文件标题
- 固定填充：来文单位="12345"，来文类型="C"，收文途径="信息中心"

### Word文件处理
- Word表格第2行第2列（来源） → 收文途径
- Word表格第3行第2列（姓名字段） → 来文单位
- 固定填充：来文类型="C"

## 注意事项

- 程序会自动排除模板文件和已生成的文件
- 确保PDF文件至少有2页，且第二页包含表格数据
- 确保Word文件包含正确格式的表格
- 编号会自动保存在`config.json`中，删除此文件可重置编号
- 每次运行程序会处理目录中所有符合条件的PDF和Word文件
- 生成的文件会累积编号，不会覆盖已存在的文件

## 技术细节

- 使用`pdfplumber`提取PDF表格数据（支持复杂表格结构）
- 使用`python-docx`读写Word文档，保持原始格式
- 编号持久化存储，程序重启后继续递增
- 自动处理单元格合并和多种文本格式
- 日期格式自动适配（YYYY-M-D格式，无前导零）
- 智能定位表格标签后的填充单元格，正确处理合并单元格
- 自动过滤临时文件（~$开头的文件）
