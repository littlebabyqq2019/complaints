═══════════════════════════════════════════════════════════
文件说明
═══════════════════════════════════════════════════════════

【app_startup.log】
用途：记录程序启动过程的详细日志
作用：诊断启动失败、闪退等问题
更新：每次启动自动覆盖（保留最新一次）

【complaints.db】
用途：SQLite数据库，存储所有批办单记录
作用：数据持久化存储
大小：随记录增加而增长（通常几KB到几MB）
重要：⭐⭐⭐ 最重要，必须备份！

【config.json】
用途：存储文件编号和收文编号
格式：{"file_number": 1, "receipt_number": 3042}
作用：确保编号连续性
更新：每次生成批办单后自动保存

【input_history.json】
用途：记录各字段的输入历史和频率
作用：提供智能输入建议（下拉菜单）
格式：{"来文单位": {"某某医院": 5, "某某局": 3}}

【path_config.json】
用途：存储自定义的文件夹路径
作用：允许用户自定义已处理、待打印等文件夹位置
格式：{"已处理": "已处理", "待打印": "待打印", ...}

【quick_buttons_config.json】
用途：存储快捷按钮的自定义内容
作用：允许用户自定义快捷填充的文本
更新：通过"设置预设内容"修改

【window_config.json】
用途：存储窗口布局和主题设置
作用：记忆窗口大小、位置、主题等
格式：{"maximized": true, "theme": "litera", ...}

【新增函数】

在 gui_app.py、main.py、database.py 中都添加了：

```python
def get_appdata_path(filename=''):
    """
    获取AppData目录下的文件路径
    
    Args:
        filename: 文件名，如果为空则返回AppData目录路径
    
    Returns:
        str: 完整的文件路径
    """
    appdata_dir = 'AppData'
    
    # 确保AppData目录存在
    if not os.path.exists(appdata_dir):
        os.makedirs(appdata_dir)
        print(f"已创建AppData目录: {appdata_dir}")
    
    if filename:
        return os.path.join(appdata_dir, filename)
    return appdata_dir
```

【修改点】

1. gui_app.py
   - InputHistoryManager: 使用 get_appdata_path('input_history.json')
   - load_path_config: 使用 get_appdata_path('path_config.json')
   - load_quick_buttons_config: 使用 get_appdata_path('quick_buttons_config.json')
   - load_window_config: 使用 get_appdata_path('window_config.json')
   - main函数: app_startup.log 使用 get_appdata_path()

2. main.py
   - CounterManager: config.json 使用 get_appdata_path()

3. database.py
   - ComplaintDatabase: complaints.db 默认使用 get_appdata_path()

【旧版本升级】

如果从旧版本（v1.35.7及以前）升级到v1.35.8：

方式1：自动迁移（推荐）
程序会在主目录和AppData目录中同时查找文件：
- 优先使用AppData目录的文件
- 如果AppData中不存在，会创建新文件
- 旧文件仍保留在主目录，不会自动删除

方式2：手动迁移
1. 创建AppData文件夹
2. 将以下文件移动到AppData目录：
   - app_startup.log
   - complaints.db ⭐ 重要！
   - config.json
   - input_history.json
   - path_config.json
   - quick_buttons_config.json
   - window_config.json

【注意事项】

⚠ 如果旧版本的complaints.db在主目录：
  - 方式1：手动移动到AppData/complaints.db
  - 方式2：使用数据库恢复功能导入旧数据
  - 方式3：重新处理文件（数据会重新录入）

⚠ 如果旧版本的config.json在主目录：
  - 手动移动到AppData/config.json
  - 或者重新设置起始编号

优势对比
═══════════════════════════════════════════════════════════

【旧方式】配置文件分散在主目录
❌ 文件分散，不便管理
❌ 备份时容易遗漏
❌ 难以区分系统文件和用户文件
❌ 目录混乱

【新方式】配置文件统一在AppData
✅ 集中管理，一目了然
✅ 备份只需复制一个文件夹
✅ 清晰的文件分类
✅ 目录整洁

常见问题
═══════════════════════════════════════════════════════════

Q1: 升级后找不到旧数据？
A: 检查主目录是否有complaints.db，手动移动到AppData/

Q2: 编号从1开始了？
A: 检查主目录是否有config.json，手动移动到AppData/

Q3: 快捷按钮设置丢失？
A: 检查主目录是否有quick_buttons_config.json，手动移动到AppData/

Q4: 窗口大小和主题重置？
A: 检查主目录是否有window_config.json，手动移动到AppData/

Q5: 如何完全重置程序？
A: 删除整个AppData文件夹，程序会自动创建新的

Q6: AppData文件夹可以改名吗？
A: 不建议，程序硬编码了这个名称

Q7: 可以把AppData放到其他位置吗？
A: 目前不支持，必须在主程序同目录
